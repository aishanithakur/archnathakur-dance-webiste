# Dance with Archna Thakur 💃

A website for my mother's Kathak and dance classes, built to showcase her teaching, awards, and performances.

🔗 **Live site:** https://dancewitharchnathakur.netlify.app

## Purpose
My mother is a Kathak artist and dance teacher. I made this site so students and parents can learn about her, see her achievements, and contact her.

## Sections
- **Home:** introduction and key stats
- **About:** her training and teaching experience
- **Wall of Fame:** awards and recognitions
- **Gallery:** performance photos
- Links to WhatsApp, Instagram, Facebook, and YouTube (WhatsApp is the main way students contact her)

## Built With
- HTML, CSS, JavaScript
- Netlify (hosting)

## About This Project
I built this with AI assistance while learning web development, and I'm now studying the code to understand and improve it myself. The design decisions, content, photos, and deployment were done by me for a real user.
